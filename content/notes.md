# Notes inbox

Rough material for the daily writer. Drop anything here, any format — a sentence, an
error message, a link, a half-thought. The writer turns the most usable note into a
`challenge` / `learnings` / `ai-vs-human` post and then **deletes the note it used**, so
this file only ever contains unwritten material.

This file is optional. When it is empty and recent GitHub activity is thin, experience
posts are skipped for the day in favour of a trending-topic post — see the guardrail in
`calendar.md`.
